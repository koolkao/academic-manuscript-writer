# Evaluation cases (fixture-backed specification)

> **Status note:** These 19 cases are fixture-backed evaluation specifications with deterministic
> `check_manuscript.py` assertions. Live end-to-end agent runs have **not** yet been executed or
> recorded in `evals/runs.md` (creating `evals/runs.md` from real isolated agent runs is the next
> empirical validation step).

Run each case against `SKILL.md` in a fresh agent that has not seen `examples/`. Every case points
to a concrete fixture in `evals/fixtures/` (or a worked example). For every case producing
manuscript or planning artifacts, run:

```bash
python3 scripts/check_manuscript.py <output-or-dir> [--stage draft|submission] [--bib <refs>]
```

**Scoring rubric:** Each case is scored **PASS / FAIL** against its concrete behavioral criteria.
Zero `FAIL`s from `check_manuscript.py` are required unless the case explicitly tests catching an
unresolved defect. Record real runs in `evals/runs.md` when executed and fix the skill instruction
that caused any failure; never weaken the rubric to match a faulty run.
